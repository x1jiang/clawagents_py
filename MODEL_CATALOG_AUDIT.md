# Gemini 4 Carbon, hosted Muse (Meta Model API), GPT-6 Cyber — 2026-11-11

Unreleased (Python) / unreleased (VS Code). Checked against the providers' own documentation on 2026-11-11; no live generation was run and no account access to the new models is claimed.

- **Gemini 4 Carbon (`gemini-4-carbon`, GA 2026-11-10):** 1,048,576-token unified window, 65,536 synchronous output tokens, `thinking_level` low / medium / high — the same request contract as Gemini 4 Argon (no `temperature` / `top_p` / `top_k`; prompt-block fallback to `gemini-3.8-flash`). Introductory pricing matches Argon: $2.00 input / $10.00 output / $0.10 cached per 1M through 2026-11-30. The pricing page lists $4.00 / $20.00 / $0.20 from 2026-12-01 for both models; the price tables still carry the introductory rates and need updating then.
- **OpenAI:** the general GPT-6 lineup (`gpt-6-astra`, `gpt-6-sol`, `gpt-6-luna`, `gpt-6.1-sol`, `gpt-6.1-terra`) was already complete; limits (1,050,000 context, 128,000 output, >272K pricing cliff) re-checked and unchanged. Added **`gpt-6-cyber`** (2026-11-05, gated behind Daybreak Red access): same window and cliff, $20 / $100 / $2 per 1M. Its page lists tools under the Responses API only and publishes no effort set, so it takes the conservative Astra-style contract (Responses for tools, effort clamped to `low` and above, no sampling parameters). It is priced and sized but not offered in the VS Code picker. `gpt-6-rosalind` (trusted access) and `gpt-6-astra-law` have no public model page and were not added.
- **Meta Model API (hosted Muse):** new `meta-api` provider profile — OpenAI-compatible at `https://api.meta.ai/v1`, key from `MODEL_API_KEY` or `META_MODEL_API_KEY` (never borrowed from another vendor). A bare `muse-spark-*`, `muse-wonder-*` or `muse-ember-*` id selects it automatically. Models: `muse-spark-1.3` (default), `muse-spark-1.2`, `muse-spark-1.1`, the `-contributor` tiers of 1.3 and 1.2, `muse-wonder-1.0` (preview), `muse-ember-1.0`. Context 1,048,576 tokens (Ember documented as "1M"); Meta publishes no output cap, so none is set. Reasoning effort is clamped to what the API accepts (`none` → `minimal`; `max` → `xhigh` on Contributor ids). Pricing per 1M: Spark $1.25 / $4.25 / $0.15 cached; Contributor $0.10 / $0.20 / $0.002; Wonder $4 / $20 / $0.20; Ember $0.10 / $0.50 / $0.004 up to 200K input and 3x on the whole request above that. No cache-write rate is published, so writes are estimated at the full input rate. The self-hosted `meta` (Muse-Glimmer) profile is unchanged. The VS Code extension has the pricing and context windows but no first-class Meta Model API provider entry yet.

# Gemini 4 Argon & Claude 5.5 support update — 2026-10-14

Release: Python 6.20.89 / VS Code 1.0.201. Add Gemini 4 Argon (`gemini-4-argon`) and the Claude 5.5 family (`claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`) across direct APIs, native AWS Bedrock (`bedrock-runtime`), and AWS Bedrock Mantle (`bedrock-mantle`).

- **Gemini 4 Argon (`gemini-4-argon`):** 1,048,576 input / 65,536 synchronous output token limits (`budget_ratio=0.90`). Omits `temperature`, `top_p`, and `top_k`; maps reasoning effort to `thinking_config={"thinking_level": "low"|"medium"|"high"}`. Direct introductory API pricing through 2026-11-30: $2.00 input / $10.00 output (including thinking tokens) / $0.10 cached input read per 1M tokens.
- **Claude 5.5 (`claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`):** 1,000,000 input / 128,000 output token limits (`budget_ratio=0.85`). All three omit `temperature`/`top_p`/`top_k` (which return HTTP 400) and support `low`, `medium`, `high`, `xhigh`, and `max` effort. Adaptive thinking is always on for `claude-opus-5-5` and `claude-sonnet-5-5` (never sending `thinking: {"type": "disabled"}`), while `claude-haiku-5-5` supports `thinking: {"type": "disabled"}` when `effort="none"`.
- **Bedrock & Mantle:** Native Bedrock supports `us.`, `eu.`, `apac.`, `au.`, `jp.`, and `global.` inference profiles (e.g. `us.anthropic.claude-haiku-5-5`, `global.anthropic.claude-haiku-5-5`, `au.anthropic.claude-haiku-5-5`, `jp.anthropic.claude-haiku-5-5`); Mantle routes `anthropic.claude-{opus,sonnet,haiku}-5-5` through `/anthropic/v1/messages`.
- **Pricing:** Direct Anthropic rates are $4/$20/$0.20/$5.00 for Opus 5.5, $2/$10/$0.10/$2.50 for Sonnet 5.5, and $0.10/$0.50/$0.01/$0.125 for Haiku 5.5 (with a 5× long-context multiplier on Haiku 5.5 when `prompt_tokens > 100,000`: $0.50/$2.50/$0.05/$0.625). Unverified AWS Bedrock Claude 5/5.5 rates remain `None` rather than substituting direct Anthropic rates.
- Primary sources: [Gemini 4 Argon](https://ai.google.dev/gemini-api/docs/models/gemini-4-argon), [Anthropic models](https://platform.claude.com/docs/en/about-claude/models/overview), [Anthropic pricing](https://platform.claude.com/docs/en/about-claude/pricing), [AWS Claude Haiku 5.5](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-anthropic-claude-haiku-5-5.html), [AWS Claude Opus 5.5](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-anthropic-claude-opus-5-5.html), [AWS Claude Sonnet 5.5](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-anthropic-claude-sonnet-5-5.html).

## Availability and pricing details

- Mantle Grok 4.6: xai.grok-4.6, /openai/v1, us-west-2. Input/output/read 2.20/6.60/.55. Global profile pricing is 2/6/.50; region choices are never rewritten automatically.
- Mantle Opus 5/Sonnet 5: us-east-1, eu-north-1, eu-west-1, ap-southeast-4 (Melbourne), plus us-gov-west-1. Native US inference profiles are separate and not subject to this Mantle restriction.
- Fable 5.1 native requires AWS review retention opt-in configured by the account/project owner. This release does not change retention consent. Its Mantle card lists GovCloud only, so it is omitted from the normal Mantle fallback. Gated Mythos models and specialized image/audio/research APIs are not advertised as ordinary coding models.
- Direct Fable 5.1 input/output/read/write 10/50/.25/12.5; Opus 5=5/25/.5/6.25; Sonnet 5=2/10/.2/2.5. New AWS Claude prices stay unknown because current AWS rates were not verified; direct-provider prices are not substituted.
- Five new generic Mantle models use published US input/output rates. Their cache tiers are unverified, so estimates use full input rates for cache tokens instead of inventing discounts. All prices remain list-price estimates, excluding storage, tools, taxes and negotiated rates.
- For AWS cards stating only 8K/16K/32K output limits, runtime caps conservatively use 8000/16000/32000. Nova 2's documented Converse cap is 65000. This avoids assuming undocumented binary expansion.

- Claude signed tool turns defer destructive context compaction until a tool-free response. Other providers and completed turns retain inline compaction. A long uninterrupted Claude tool chain can reach its context limit before that boundary. Fable 5.1 uses the documented binding-control beta to recover from changed prefixes; signatures are never rewritten.
